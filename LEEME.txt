EPOANT · EXPEDIENTE · GITHUB IFRAME ESTABLE

OBJETIVO
Evitar el bloqueo de inicio de sesión del bridge GitHub -> Apps Script.

ARQUITECTURA
GitHub/expediente.edupsic.com muestra dentro de un iframe la aplicación publicada
por Apps Script. La aplicación completa sigue ejecutándose dentro de Apps Script,
por lo que google.script.run funciona de forma nativa.

IMPORTANTE
- NO cambies Code.gs.
- NO cambies Index.html de Apps Script.
- El filtro por grupos y Cumplimiento ya deben estar en el Index de Apps Script.
- En GitHub sustituye únicamente index.html y conserva CNAME/.nojekyll.

INSTALACIÓN EN GITHUB
1. Sube index.html, CNAME y .nojekyll a la raíz del repositorio.
2. Sustituye el index.html actual.
3. Commit changes.
4. Espera 1-3 minutos.
5. Abre https://expediente.edupsic.com y fuerza recarga:
   Mac: Cmd+Shift+R
   Windows: Ctrl+Shift+R
